# 📒 Address Book in C

A menu-driven **Address Book** application developed in **C** as part of the Emertxe Embedded Systems Program.

This project demonstrates the implementation of a contact management system using file handling, modular programming, and dynamic user interaction through a command-line interface.

---

## 🚀 Features

- ➕ Add a new contact
- 📋 List all contacts
- 🔍 Search contacts
- ✏️ Edit contact details
- ❌ Delete contacts
- 💾 Store contacts in a file
- 📂 Load contacts from a file on startup
- ✔️ Input validation for contact details

---

## ⚙️ Build & Run

Compile the project:

```bash
make
```

Run the executable:

```bash
./address_book
```

*(If your executable has a different name, replace `address_book` with the correct executable name.)*
